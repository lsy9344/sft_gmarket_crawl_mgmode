Slide 1. 왜 외부 플랫폼 연동이 필요한가?

지마켓과 쿠팡의 대규모 상품 정보를 안정적으로 수집하기 위한 핵심 통신 인프라

지마켓 카테고리 수집

  • 연동 플랫폼: Bright Data
  • 사용 솔루션: Web Unlocker (존: gm_unlocker)
  • 주요 목적: 수천 개 카테고리 상품 목록 무중단 로드
  • 과금 방식: 성공한 요청 건당 소액 차감 (건당 약 $0.0015)

쿠팡 카테고리 수집

  • 연동 플랫폼: Decodo
  • 사용 솔루션: 대한민국 주거용 고정 회선 (Residential Sticky)
  • 주요 목적: 쿠팡 엄격 보안망 통과 및 카테고리 탐색
  • 과금 방식: 실제 사용한 데이터 트래픽(GB) 단위 차감
💡 안전한 계정 관리: 사용자가 직접 공식 플랫폼에서 발급받은 계정 키를 등록하므로 불필요한 중간 수수료가 없으며, 인증 키는 사용자 PC 내부 로컬 환경에만 안전하게 보관됩니다.

Slide 2. Gmarket: Bright Data API 토큰 발급

brightdata.com 콘솔에서 Web Unlocker 존 생성 및 API 토큰 발급
1
가입 및 결제 등록: brightdata.com 접속 후 가입 → Billing 메뉴에서 크레딧 충전 또는 카드 등록
2
Web Unlocker 존 생성: Proxies & Scraping → Add → Web Unlocker 선택 → 존 이름 입력 (권장: gm_unlocker)
3
API 토큰 생성: 좌측 하단 Settings(설정) → API Tokens → [+ Generate Token] 클릭
4
토큰 복사: 생성된 토큰 문자열(brd_api_key_...) 옆의 [Copy] 버튼 클릭

Slide 3. Coupang: Decodo 프록시 계정 발급

decodo.com 콘솔에서 대한민국 주거용 프록시 전용 인증키 확인
1
가입 및 플랜 활성화: decodo.com 접속 → Proxy Plans에서 Residential Proxies(주거용 종량제, 1GB 약 $4) 구매
2
Authentication 탭 이동: 좌측 메뉴 Residential Proxies 클릭 → 상단 [Authentication] 탭 선택
3
전용 인증 정보 복사: Proxy Credentials 영역의 Proxy Username(예: sp3lqmo64w) 및 Proxy Password 복사
⚠️ 주의: 웹사이트 로그인 이메일/비밀번호가 아닙니다! 반드시 Authentication 대시보드에 표기된 전용 Username과 Password를 사용해야 합니다.

Slide 4. 프로그램 [설정] 탭 등록 및 즉시 검증

수집 프로그램 설정 탭에 키 입력 및 원클릭 연결 유효성 테스트

Bright Data 등록 (지마켓용)

  • Bright Data API 토큰: 복사한 토큰 붙여넣기
  • Unlocker 존: gm_unlocker 입력
  • 출발 국가: kr (한국 상품 목록 기준)
  • [잔액 조회·토큰 검증] 클릭 → 잔액 확인
  • [저장] 클릭으로 완료

Decodo 등록 (쿠팡용)

  • Decodo 사용자명: 복사한 Username (sp3xxxxxx)
  • Decodo 비밀번호: 복사한 Password 입력
  • [Decodo 계정 저장] 클릭
  • "Decodo 저장됨" 확인 후 즉시 사용 가능

Slide 5. 실전 수집 시작 및 운용 체크포인트

카테고리 탭에서 원하는 품목 선택 후 안정적인 수집 시작
구분 Gmarket 카테고리 수집 Coupang 카테고리 수집
카테고리 선택 대/중/소분류 다중 선택 및 전체 선택 가능 안정성을 위해 1회당 카테고리 1개 순차 선택 권장
권장 설정 기본 딜레이 (8~12초) 유지 24시간 한국 고정 세션으로 세션 안정성 유지
중단 시 대처 일시정지 후 언제든 재개 가능 [재개] 버튼으로 마지막 수집 지점부터 연속 수집

자가 진단 가이드

  • 인증 오류 (401/403): 토큰 앞뒤 공백 확인 후 재입력 및 [잔액 조회·토큰 검증] 클릭
  • 프록시 인증 에러 (407): Decodo 웹 로그인 비번이 아닌 Authentication 전용 키인지 재확인
  • 요청 제한 (429) / 잔액 소진: 해당 플랫폼의 Billing 페이지에서 크레딧 잔액 확인 후 충전
