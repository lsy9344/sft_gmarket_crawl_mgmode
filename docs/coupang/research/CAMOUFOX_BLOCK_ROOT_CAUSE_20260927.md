## 결론

**차단 주체는 쿠팡 앞단의 Akamai 엣지(AkamaiGHost)이고, 차단 판정은 네트워크 계층(TLS ClientHello/HTTP2)에서 첫 document 요청 시점에 내려진다. Camoufox가 걸리는 이유는 Camoufox 0.5.4가 Firefox 152.0.4-beta.28에 고정돼 있어, 현재 정식 Firefox(156.0.1)가 더 이상 내보내지 않는 구형 TLS ClientHello 프로파일을 내기 때문이다.** 이 구형 프로파일은 실사용자가 거의 존재하지 않고(Firefox 자동업데이트) 전 세계 스크래퍼 도구들(Camoufox, curl_cffi Firefox 모방 등)이 공유하는 지문이라 Akamai가 위험 코호트로 분류한다.

같은 시각·같은 회선 대조로 확정한 사실:

| 클라이언트 | 네트워크 지문 | 쿠팡 www 결과 |
|---|---|---|
| Patchright Chromium 149 (직접/Decodo) | Chrome 계열 (JA4 `t13d1516h2_8daaf6152771_...`) | **200 통과** — 오늘 밤 전 시점 통과 |
| **공식 Firefox 156.0.1** (현재 정식) | 신형 Firefox (JA4 `t13d1517h2_8daaf6152771_...`) | **200 통과** — 홈 정상 렌더 확인 |
| Camoufox 0.5.4 (152.0.4-beta.28) | 구형 Firefox (JA4 `t13d1617h2_86a278354501_...`) | **403 AkamaiGHost** — Decodo/직접 모두 |
| Playwright Firefox 150.0.2 (구형 계열) | 구형 Firefox (Camoufox과 JA3/JA4/H2 **완전 동일**) | 시점에 따라 200/403 혼재 |
| curl_cffi firefox147 모방 (브라우저 없음) | 구형 Firefox | 403 |
| curl_cffi chrome150 모방 + Firefox UA | Chrome 계열 | 200 |

공식 Firefox 156과 Camoufox는 **HTTP/2 지문이 완전히 동일**(`1:65536;2:0;4:131072;5:16384|12517377|0|m,p,a,s`)한데 156은 통과하고 Camoufox는 차단된다. 양자의 와이어 차이는 TLS ClientHello의 cipher 구성뿐(156이 구 cipher 1종을 정리, JA4 두 번째 세그먼트 상이)이다. 즉 **"Firefox라서" 차단이 아니라 "현행 정식 Firefox가 내지 않는 구형 ClientHello 코호트여서" 차단**이다. Playwright Firefox 150(구형 프로파일)이 시점별로 통과/차단가 요동한 것은 이 코호트가 경계 점수부(적응형 판정)로 관리된다는 관측과 일치한다. 단, Akamai 내부 점수 로직은 외부에서 완전히 확인 불가하며 이 부분은 추정 범위로 명시한다.

## 의미와 권고

1. **Chromium(Patchright) 전환 유지가 정답.** 오늘 밤 모든 시점·회선에서 통과. 이유까지 확정됐으니 재검토 없이 유지한다.
2. **Camoufox는 설정·버전 조정으로 회복 불가.** 차단 원인이 JS 지문이나 설정이 아니라 Firefox 엔진의 네트워크 스택이 내는 구형 ClientHello 자체다. Camoufox 패키지가 최신 정식 Firefox 베이스로 리베이스되어 ClientHello가 신형 프로파일(공식 156류)이 되기 전까지는 www.coupang.com에서 재차 차단된다. 업스트림(daijro/camoufox)의 베이스 버전을 확인한 뒤 재시도할 것.
3. **아직 Camoufox를 쓰는 남은 경로(일반 Coupang 탭, 로그인, 카테고리 목록 갱신)는 www.coupang.com 진입이 필요한 순간 동일 차단에 노출된다.** 8/31 사고가 바로 이 경로에서 발생했다. 별도 작업으로 Chromium 전환 또는 진입 선검사를 검토한다.
4. **재검증 절차(1분):** `evidence-camoufox-block-20260927/matrix.py`를 실행해 chrome150-계열 200 / firefox147-계열 결과를 본다. firefox 계열이 200으로 돌아오면 규칙 완화 신호. Camoufox 복귀 검토는 그때 실시한다.

## 후기(2026-09-28 00:0x): Chromium 측 일시 차단 관찰 — 별개 메커니즘
