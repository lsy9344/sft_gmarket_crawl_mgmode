## Decodo 실제 계정 사용량 조회

기존 계정 조회 키로 공식 API에 읽기 전용 조회를 했다. 앱의 프록시를 통해 쿠팡에 추가 요청을 보내지는 않았다.

| 구분 | 조회값 | 사용자 계정의 $4/GB로 환산 |
|---|---:|---:|
| 최근 24시간 사용량 (`type=24h`) | 약 0.29GB | 약 **$1.16** |
| 누적 사용량 (9/10 계정 집계 시작 이후) | 약 3.30GB | 약 **$13.20** |
| 현재 구독의 총 제공량 | 4GB | 결제 내역 자체는 미조회 |
| 남은 제공량 (`4 - 3.30`) | 약 **0.70GB** | 잔여 Wallet 현금과는 별개 |

최근 24시간 응답은 `traffic=0.29`, `traffic_rx=0.24`, `traffic_tx=0.05`였다. 날짜 조건 `2026-09-27`~`2026-09-28`로 별도 조회한 값도 같았다. API 공개 문서가 시각대와 개별 응답 필드의 세부 단위를 명시하지 않으므로, 시간 범위는 API의 “최근 24시간” 조건으로 표기하고 소수 표시값의 금액 환산은 근사치로 취급한다. 계정의 4GB 제공량 및 GB 사용량 체계와 대조해 정리했다.

**$1.16은 최근 24시간의 계정 전체 사용량에 해당하는 환산 금액이다.** Sandbox 수집, 실패·재시도, 같은 계정으로 다른 곳에서 한 프록시 시험이 함께 포함된다. 실행 전·후 사용량 기준값이 없으므로 이번 Sandbox 수집만의 비용이나 카테고리별 비용을 정확히 나누지는 못한다. 세금과 실제 Wallet 차감·충전 거래는 이 계산에 포함하지 않았다.

상세 시간별 통계 API는 이 계정에서 HTTP 409 `Subscription resources not available yet`로 응답했다. 따라서 시간별 분배나 이번 수집만의 정확한 사용량을 임의로 추산하지 않았다.

Decodo PAYG는 Wallet에서 1GB씩 구매하며 소진에 따라 다음 1GB를 자동 구매한다. 따라서 사용량을 단가로 환산한 금액과 실제 Wallet 차감 단위가 다를 수 있다. 사용자가 말한 $10은 Wallet 충전액으로, 이번 수집에 $10을 썼다는 의미가 아니다. [Decodo 공식 결제 안내](https://decodo.com/faq/billing/how-does-the-monthly-subscription-model-work).

조회 방법과 단위 참고: [Sub-user traffic API](https://help.decodo.com/api-reference/sub-users/get-sub-user-traffic), [상세 traffic API](https://help.decodo.com/api-reference/traffic/get-traffic), [Decodo GB 표시 안내](https://decodo.com/faq/getting-started/what-is-changing-in-traffic-calculation), [Residential PAYG 가격](https://decodo.com/proxies/residential-proxies/pricing). 모두 2026-09-28 확인.
