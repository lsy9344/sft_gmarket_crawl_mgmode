1. **층1 SRP**: 키워드 검색은 정렬당 60개 상한, 페이지네이션은 비로그인 세션에

2. **층2 가격 밴드**: 페이지 내장 공식 밴드 5종 각각 독립 결과 셋.
3. **층3 카테고리 PLP**: 비로그인에서 ?page=1..17 SSR — 실질 상품 풀은
   카테고리당 ~200~900개. 뷰티 트리 14개 카테고리 전부 순회 완료.
4. 로켓배송(쿠팡 직매입) 제외 후 3자 판매자만 수집. 운영 규율(세션 간격 ≥30분,
   일일 ≤5, 딜레이 15~20초, 차단 즉시 중단) 준수.
