1. 처음 한 번만 준비하기

① EXE가 있는 폴더에서 명령 프롬프트 열기

파일 탐색기에서 SellerCollector.exe가 있는 폴더를 엽니다. 주소창에 cmd를 입력하고 Enter를 누릅니다.

② 브라우저 런타임 설치

SellerCollector.exe --setup-runtime

인터넷에서 Gmarket·Coupang용 브라우저와 GeoIP 데이터를 설치합니다. 약 1.4GB를 내려받을 수 있으며, 완료될 때까지 창을 닫지 마세요.

③ 설치 확인

SellerCollector.exe --verify-runtime

마지막에 성공 메시지가 나오고 종료 코드가 0이면 준비가 끝난 것입니다.

④ 프로그램 실행

SellerCollector.exe를 더블클릭합니다. 화면 위쪽에서 Gmarket 또는 Coupang 탭을 선택합니다.

권장 첫 테스트
Gmarket은 카테고리 1개·수집 수량 10개, Coupang은 최대 피드 페이지 1로 시작하세요.
같은 사용자 계정 사용
설치 명령과 GUI를 같은 Windows 사용자로 실행해야 합니다. 설치 명령만 관리자 계정으로 실행하지 마세요.

2. Gmarket 탭 사용하기

순서할 일
1카테고리: 처음에는 전체 선택을 끄고 원하는 항목 1개만 선택합니다.
2수집 수량: 첫 테스트는 10을 권장합니다. 요청 간격은 기본값 0.5초를 유지합니다.
3저장 경로: 로컬 폴더를 선택합니다. 공유 폴더나 네트워크 드라이브는 사용하지 마세요.
4사전 조사: 전체·신규·이미 수집 건수를 확인합니다.
5신규 대상이 있으면 수집 시작을 누릅니다.
6완료 후 저장 폴더에서 JSON·CSV 결과를 확인합니다.

사전 조사 뒤 카테고리나 저장 경로를 바꾸면 사전 조사를 다시 실행해야 합니다.

3 / 5

3. Coupang 탭 사용하기

순서할 일
1출력 폴더에서 결과를 저장할 로컬 폴더를 반드시 선택합니다.
2첫 테스트는 최대 피드 페이지 1로 설정합니다.
3배치 10, 웜업 20초, 지연 최소 1.0초·최대 2.5초는 기본값을 유지합니다.
4출력 prefix는 선택 사항입니다. 비우면 파일 이름이 자동 생성됩니다.
5수집 시작을 누르고 단계·진행·통계와 로그를 확인합니다.
6완료 후 결과 열기를 눌러 JSON·CSV 파일을 확인합니다.
동시에 실행하지 마세요.
Gmarket과 Coupang은 한 번에 하나만 실행됩니다. 한 탭의 작업을 끝내거나 취소한 뒤 다른 탭을 시작하세요.

4. 버튼·결과·문제 해결

버튼기능
일시정지현재 처리 뒤 잠시 멈춥니다. 재개로 계속합니다.
취소현재 요청을 정리한 뒤 중단하며, 수집된 내용은 부분 결과로 저장됩니다.
이어서 수집Gmarket의 남은 신규 대상만 다시 조사해 이어서 수집합니다.
초기화Gmarket 수집 이력과 진행 상태를 지웁니다. 전체를 다시 수집할 때만 사용하세요.

자주 발생하는 문제

  • 런타임 미준비: 프로그램을 닫고 --setup-runtime을 다시 실행한 뒤 --verify-runtime으로 확인합니다.
  • Gmarket 수집 시작 버튼이 비활성: 카테고리를 선택하고 먼저 사전 조사를 실행합니다.
  • Coupang 시작 불가: 출력 폴더가 입력됐는지, 다른 탭이 실행 중인지 확인합니다.
  • 방화벽 알림: Gmarket 첫 실행 때 Chromium 인바운드 알림이 나오면 창을 닫아도 됩니다.
  • 30일 뒤 Coupang 실행 거부: GeoIP 갱신을 위해 --setup-runtime을 다시 실행합니다.
  • 결과 위치를 모름: 선택한 저장 폴더를 확인하거나 Coupang의 결과 열기를 누릅니다.
중단해야 하는 경우
403·429 오류, CAPTCHA, 사이트 차단 메시지 또는 비정상 오류가 반복되면 즉시 취소하고 운영 책임자에게 확인하세요.
종료 방법
작업이 끝난 뒤 창의 X 버튼으로 종료합니다. 수집 중이면 종료 확인창에서 안전한 중단을 선택하세요.
