## 2. 데이터 품질 검증 기준

1. **이메일 주소 (`email`)**:
   - 도메인 포함 정규식 검증 (`@` 포함). 네이버, 회사 자체 도메인 등.
   - 쿠팡과 동일하게 B2B 영업 및 마케팅의 핵심 필드.
2. **대표자명 (`ceo_name`)**:
   - 사업자등록상의 실제 성명.
3. **사업자등록번호 (`business_number`)**:
   - 한국 국세청 10자리 정규 번호 (하이픈 제외 또는 포함).
4. **전화번호 (`phone`)**:
   - 유선전화, 휴대폰, 또는 대표번호(1588, 1800 등).
