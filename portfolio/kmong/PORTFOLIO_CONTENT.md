## 프로젝트 설명 — 그대로 붙여 넣기

온라인 쇼핑몰 운영 과정에서 반복적으로 발생하는 판매자 사업자 정보 확인 업무를 줄이기 위해 개발한 Windows 데스크톱 자동화 프로그램입니다.

Gmarket과 Coupang의 서로 다른 데이터 구조를 하나의 2탭 UI로 통합했습니다. 사용자는 카테고리, 수집 수량, 요청 간격, 저장 경로를 설정한 뒤 실제 수집을 시작하기 전에 사전 조사를 실행할 수 있습니다. 사전 조사 화면에서는 전체 상품 수, 신규 대상, 이미 수집한 대상, 예상 소요 시간을 먼저 확인할 수 있어 작업 범위를 예측하고 실행 여부를 결정할 수 있습니다.

수집 중에는 현재 카테고리, 진행률, 성공·실패 수, 속도와 예상 잔여 시간을 실시간으로 표시합니다. 일시정지, 재개, 취소, 이어서 수집을 지원하며, 중간 종료나 파일 손상 상황에서도 결과가 유실되지 않도록 체크포인트 복구, 중복 방지, 원자적 JSON/CSV 저장, fail-closed 오류 처리를 적용했습니다.

코어 수집 엔진과 PyQt6 UI를 분리하고 QThread와 Signal로 연결해 장시간 작업 중에도 화면 응답성을 유지했습니다. 결과는 카테고리별 파일과 통합 파일로 저장되며, Excel에서 바로 열 수 있는 UTF-8 BOM CSV와 구조화된 JSON을 함께 제공합니다. Windows에서는 단일 EXE로 패키징하고 런타임 설치·검증 모드, GUI 스모크 테스트, 사용자 매뉴얼까지 준비했습니다.

개발·인수 검증 환경에서 Gmarket 22개 카테고리 수집 흐름과 Coupang 판매자 데이터 파이프라인을 확인했고, Linux와 Windows에서 각각 240개의 자동화 테스트를 통과했습니다. 실제 운영 수집은 대상 사이트의 이용약관, robots 정책, 의뢰인의 데이터 이용 권한을 확인한 범위에서만 진행합니다.
