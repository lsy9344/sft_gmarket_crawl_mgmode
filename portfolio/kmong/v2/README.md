# 크몽 포트폴리오 이미지 v2

2026-08-31 제작. 기존 `../images/`(스크린샷 합성 방식)를 대체하는 새 디자인 세트.
HTML로 디자인하고 헤드리스 크로미움으로 2배 해상도 PNG를 렌더링했다.

## 업로드 순서와 규격

| 순서 | 파일 | 크기(px) | 용도 |
| --- | --- | --- | --- |
| 메인 | `images/01_main_cover.png` | 2400×2400 (1:1) | 대표 이미지 — 핵심 메시지 + 제품 목업 + 수치 4종 |
| 상세 1 | `images/02_workflow.png` | 2400×2740 | 사용 흐름 4단계 (사전 조사 → 수집 → 중단 안전 → 결과물) |
| 상세 2 | `images/03_product_ui.png` | 2400×2660 | 실제 화면 구성 재현 + 번호 설명 |
| 상세 3 | `images/04_reliability.png` | 2400×2400 | 데이터 안전장치 4종 + 납품 범위 |

크몽 규격(메인 1:1·가로 600px 이상, 상세 세로 3000px 이하)을 모두 충족한다.
등록 문구·키워드·설명은 기존 `../PORTFOLIO_CONTENT.md`, 등록 절차는 `../UPLOAD_GUIDE.md`를 그대로 사용한다.

## 디자인 메모

- 톤: 신뢰 중심 네이비(#0F172A) + 블루 CTA(#0369A1/#38BDF8), Pretendard 서체
- 화면 속 데이터는 전부 가상의 예시(마스킹된 사업자번호·가명 상호)이며 실제 수집 결과가 아니다
- 정책 준수 문구("이용 권한을 확인한 범위…")를 상세 이미지 하단에 고정 표기

## 재생성

```bash
./portfolio/kmong/v2/render_images.sh
```

`source/*.html`을 수정한 뒤 위 스크립트를 실행하면 `images/`가 갱신된다.
서체는 `source/fonts/PretendardVariable.woff2`(로컬 포함)를 사용한다.
