# 크몽 포트폴리오 등록 가이드

기준일: 2026-08-04

## 확인한 현재 등록 구조

크몽은 2026-07-15부터 포트폴리오 등록 화면을 `기본 정보 → 상세 정보 → 연관 서비스`의 3단계로 구분한다. 상세 설명은 최소 10자 이상이며, NDA 등으로 고객사명을 공개하기 어려운 경우 비공개 체크박스를 사용할 수 있다.

이 패키지는 아래 공식 규격을 충족한다.

| 항목 | 크몽 공식 규격 | 준비 파일 |
| --- | --- | --- |
| 메인 이미지 | 가로 600px 이상, 1:1 | 1200×1200 PNG 1장 |
| 상세 이미지 | 가로 600px 이상, 세로 3000px 이하 | 1200×1400 2장, 1200×1000 1장 |
| IT 기술 | 작업 범위 및 기술 최소 1개 | Python 외 권장 기술 정리 완료 |
| 상세 설명 | 최소 10자 이상 | 프로젝트 설명 작성 완료 |

공개 공식 문서에서는 포트폴리오 이미지의 허용 확장자, 개별 파일 용량, 상세 이미지 최대 장수, 제목·키워드 최대 개수를 확인할 수 없었다. 업로드가 거절되면 실제 등록 화면의 안내에 맞춰 PNG를 JPG로 변환하거나 용량을 조정한다.

## 등록 순서

1. `주문 관리 → 판매 관리 → 내 포트폴리오 → 포트폴리오 등록하기`로 이동한다.
2. 기본 정보에 `PORTFOLIO_CONTENT.md`의 카테고리, 제목, 키워드를 입력한다.
3. 메인 이미지와 상세 이미지 3장을 번호 순서대로 올린다.
4. 상세 정보에 프로젝트 설명, 기간, 고객사, 업종, 참여 영역, 기술을 입력한다.
5. 고객사를 공개할 수 없으면 비공개 체크박스를 선택한다.
6. 같은 `IT·프로그래밍 > 크롤링·스크래핑` 카테고리의 판매 서비스만 연관 서비스로 연결한다.
7. 본인 창작물 확인과 신고 시 삭제 가능성 약관을 확인한 뒤 제출한다.

## 제출 전 최종 점검

- [ ] 참여 기간이 실제 프로젝트 기간과 일치한다.
- [ ] 고객사 공개 가능 여부를 확인하고 필요하면 비공개 처리했다.
- [ ] 한 포트폴리오에 이 프로젝트 외 다른 작업을 섞지 않았다.
- [ ] 전화번호, 이메일, SNS, 외부 링크, QR코드를 넣지 않았다.
- [ ] 실제 사업자 이메일·전화·사업자번호·주소 등 결과 데이터가 보이지 않는다.
- [ ] 로컬 파일 경로, 인증서 정보, 내부 해시가 보이지 않는다.
- [ ] `무단 크롤링`, `차단 우회`, `수익 보장`처럼 정책 위반 또는 오인을 부르는 표현을 사용하지 않았다.
- [ ] 공개 데이터 또는 의뢰인이 이용 권한을 보유한 데이터만 대상으로 한다는 범위를 설명했다.
- [ ] 연관 서비스의 카테고리가 포트폴리오와 같다.
- [ ] 업로드 직전 이미지 확장자·용량·장수 제한을 실제 화면에서 확인했다.
